Rclone Backup

Privacy policy

Effective date: 19 October 2026

This policy describes the personal desktop Google Drive OAuth configuration called Rclone Backup, maintained by lieyingtianlian-max, and this informational website. It covers the owner's use of rclone with the drive.file scope. It does not describe other rclone configurations or promise protections for software or services operated by others.

Data accessed and purpose

When the owner authorizes the app, rclone receives OAuth authorization tokens and uses the Google Drive API to access permitted file contents and metadata, such as names, file IDs, sizes, modification times, and folder information. These are used to upload personal backups, list or check backup files, restore or download files, and perform updates or deletions requested through rclone commands.

The requested scope is https://www.googleapis.com/auth/drive.file. It allows access to files created by the app or otherwise explicitly authorized for it. In ordinary rclone use, this means files and folders rclone creates; it does not automatically expose all existing Drive files. This configuration does not request Gmail access. Google account sign-in takes place with Google; this website does not ask for a Google password.

Processing and storage

Rclone runs on the owner's computer and communicates with Google to authorize access and transfer data. Backup files are stored in the owner's Google Drive; source files and restored copies remain wherever the owner saves them locally. No separate backup server is operated by this project.

OAuth access and refresh tokens are normally stored in the rclone configuration on the computer running rclone, along with configured OAuth client settings. Configuration location and protection depend on the installation. Rclone configuration encryption is optional; this policy does not claim it has been enabled. File encryption is also not provided by this website, and this policy does not claim that backups are end-to-end encrypted.

Depending on the commands and settings used, rclone may write logs or cache files containing file names, paths, metadata, or diagnostic details. The owner controls those settings and local files.

Sharing and other uses

Google receives data needed to provide OAuth authorization and Drive storage. This personal setup does not send Google user data to an additional project-operated service, sell that data, use it for advertising, or use it to train AI models. It does not provide another person with access to the owner's backup files. Any sharing the owner separately configures in Google Drive or other tools is outside this setup.

This website and third-party services

This is a static informational site hosted on GitHub Pages. The pages contain no analytics scripts, tracking pixels, sign-in forms, or application cookies. They do not receive backup contents or OAuth tokens. GitHub may collect visitor information, including IP addresses, in providing its hosting service; see the GitHub Privacy Statement. Google's handling of account and Drive data is described in the Google Privacy Policy.

Retention, deletion, and revoking access

Backup files remain in Google Drive until the owner deletes them or an owner-configured operation removes them. Local source files, restored files, configuration, logs, and caches remain until the owner removes them or configured cleanup applies. Google Drive trash, version history, and provider retention may affect when cloud copies are permanently removed; this project cannot promise immediate erasure.

The owner can revoke the app's access in Google Account third-party connections and remove its local rclone configuration and token copies. Revoking access stops future authorized access but does not itself delete existing backups, downloaded files, or logs. To remove backup data, delete the relevant Drive files and manage the Drive trash separately.

Changes and contact

If the setup's data practices change, this policy should be updated before those new practices are used. The effective date above identifies this version.

For questions, contact the maintainer through GitHub issues. These are public; do not post tokens, OAuth client secrets, private files, or sensitive logs.
