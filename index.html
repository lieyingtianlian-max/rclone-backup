Personal desktop use

Rclone Backup

A personal Google Drive OAuth desktop app configuration used with rclone to back up and restore the owner's files.

This project documents an individually operated backup setup. It is not a hosted backup service, and this website does not perform backups or offer a Google sign-in form.

How it works

The owner runs rclone on their own computer and authorizes the desktop OAuth client through Google's authorization page. Rclone then transfers selected files between that computer and Google Drive, according to the commands the owner runs. Depending on the command, this can include creating, reading, updating, downloading, or deleting accessible backup files and folders.

Google Drive permission

The intended Drive permission is https://www.googleapis.com/auth/drive.file. It permits access to files created by the app or otherwise explicitly authorized for use with the app, rather than unrestricted access to the entire Drive.

In ordinary rclone use with this scope, rclone can work with files and folders it creates. Files uploaded through the Drive website or another app generally will not be visible to it. This setup is suited to creating personal backups; it is not intended to read or back up an entire pre-existing Drive.

See rclone's scope documentation and Google's Drive scope documentation.

Data and control

File contents and metadata are processed by rclone on the owner's computer and by Google Drive to carry out the requested operations. OAuth tokens are normally saved in the local rclone configuration. This website does not receive those tokens or backup files. Read the privacy policy for storage, retention, and revocation details.

Contact

For project questions, contact the maintainer through the repository's GitHub issues. Issues are public: do not include credentials, tokens, private files, or sensitive logs.
